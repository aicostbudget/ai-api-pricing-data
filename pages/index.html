AI API Pricing Dataset: static JSON and CSV API

Source-linked LLM and AI API prices for OpenAI, Anthropic Claude, Google Gemini, xAI, DeepSeek, Mistral AI, Cohere, Moonshot AI (Kimi), Alibaba Qwen and Meta. Every record links to the provider's own pricing page; unknown prices stay null, never 0.

Build metadata: api/v1/meta.json

curl -L https://aicostbudget.github.io/ai-api-pricing-data/api/v1/prices.json

Endpoints

/api/v1/prices.jsonEvery model, latest prices
/api/v1/prices.csvThe same records as CSV
/api/v1/meta.jsongenerated_at, last_verified_at, counts
/api/v1/providers/<provider>.jsonOne provider, e.g. openai
/api/v1/models/<provider>/<model>.jsonOne model, e.g. openai/gpt-4.1
